# Netflix-Data-Visualization
Netflix dataset analysis and data visualization using Python, Pandas and Matplotlib
# Netflix Data Visualization Project

## About
This project analyzes Netflix movies and TV shows using Python and data visualization techniques.

## Dataset
- 8,007 rows (practice dataset)
- 12 columns:
  - show_id
  - type
  - title
  - director
  - cast
  - country
  - date_added
  - release_year
  - rating
  - duration
  - listed_in
  - description

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Visualizations
- Movies vs TV Shows
- Top 10 Countries
- Content Ratings
- Movie Duration Histogram
- Release Year Scatter Plot

## Project Files
- `Project.ipynb` — Main analysis notebook
- `netflix_practice_8007_rows.csv` — Dataset
- PNG files — Visualization graphs

## How to Run
1. Download the repository.
2. Open Jupyter Notebook.
3. Open `Project.ipynb`.
4. Run the notebook cells.
